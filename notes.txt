Ansible
=========
==>ansible is open source automation tool used for configuation management,
	application deployment, orchestration, and IT infrastructure automation.
==>it is devloped in python language.
==>control node:where ansible is installed and command are executed.
==>Manage nodes:system being configured.
==>inventory-list of managed node.
==>playbook:file containing automation instrution (written in YAML).

ansible ad-Hoc command
-----------------------
==>we have many module in ansible to perform configuation management
	->ping
	->shell
	->copy
	->yum 
	->service

==>Ping module:check connectivity between the control node and managed node.
	->$ ansible all -m ping

shell module:execute shell command in managed nodes

	-->ansible dbservers -m shell -a uptime

yum module(for RHEL/centOS):install update or remove package

	-->ansible webservers -m yum -a "name=git state=present"
	-->ansible webservers -m yum -b -a "name=git state present"
	-->ansible webservers -m yum -b -a "name=httpd state present"

	-m:specifies the module
	-a:specifies the module argument
	-b:runs with become (sudo) previleges

---------------------------------------------
==> Service Module

Manages services (start/stop/restart).

ansible webservers -b -m service -a "name=httpd state=started"
ansible webservers -b -m service -a "name=httpd state=restarted"

-------------------------------------

==> Copy Module

Copies files from control node to managed nodes.

ansible webservers -m copy -a "src=/tmp/index.html dest=/var/www/html/index.html"

Ansible Playbooks
=================

==> A Playbook is a YAML file that contains automation instructions for Ansible.

==> Defines what tasks to perform.

Benefits:

Automates repetitive tasks.

Maintains configuration consistency across environments.

Writing Playbook
================
it contains three section
->host section:represent target manchine. this config depends on ansible inventory 
	file.
->varible section:used to declare variables required in playbook execution.
->task section:define the task activity/opearation which we want to perform on 
	managed node in ansible.

==>playbook to ping all nodes
	------
	- hosts: all
	  tasks:
	  - name: ping all managed nodes
	    ping:
	    remote_user: ansible
	-------
==>command to run:ansible-playbook <playbook-filename> "ansible-playbook 
	01-ping.yml"
