Tomcat Setup
============
==>Install Java Runtime:Prerequisite.Tomcat requires Java to run. Install Amazon 
   Corretto 17:sudo dnf install -y java-17-amazon-corretto-devel
==>Download the official Tomcat 9 binary archive into your home folder: cd ~
	wget https://downloads.apache.org/tomcat/tomcat-9/v9.0.121/bin/apache-tomcat-9.0.121.tar.gz
==>Extract the Archive:tar -xvzf apache-tomcat-9.0.121.tar.gz
==>Start Apache Tomcat:Execution.Run the startup script->
	~/apache-tomcat-9.0.121/bin/startup.sh
==>Verify Tomcat is Listening:curl -I http://localhost:8080

==>Stop Tomcat:Shutdown script.Run the shutdown script to stop the running Tomcat 
   server:~/apache-tomcat-9.0.121/bin/shutdown.sh
==>Ensure the Process Is Completely Stopped:Kill lingering process (Optional).If 
	Tomcat hangs or doesn't stop after a few seconds, force kill any remaining process:pkill -9 -f tomcat
==>Start Tomcat Again:Startup script.Execute the startup script to start the server 
   fresh:~/apache-tomcat-9.0.121/bin/startup.sh

Access from Your Web Browser
============================
1
Get Your New Public IP
Terminal Check
Retrieve the public IP assigned to this EC2 instance:

Bash
curl -s http://checkip.amazonaws.com

Verification: It prints your public IPv4 address to the terminal.

2
Verify Security Group Port 8080
AWS Console
Since this is a new EC2 instance (ip-172-31-10-38):

Open the AWS EC2 Console → Instances.

Select your running instance and open the Security tab.

Click the Security Group link.

Under Inbound rules, ensure there is a rule for:

Port: 8080

Protocol: TCP

Source: 0.0.0.0/0

Verification: The Inbound rules table displays port 8080 enabled for IPv4.

3
Load the Application
Web Browser
Open a browser tab and navigate to:

Plaintext
http://<YOUR_PUBLIC_IP>:8080/webapp/

Verification: The page loads with your styled container, heading, and working button that updates text on click.
